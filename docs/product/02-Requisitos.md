## Requisitos funcionais:
RF01 - O sistema deve permitir o cadastro de usuário.
RF02 - O sistema deve permitir que o usuário edite seus próprios dados cadastrais.
RF03 - O sistema deve permitir a recuperação de acesso por redefinição de senha.
RF04 - O sistema deve permitir o usuário excluir sua própria conta.
RF05 - o sistema deve permitir autenticação de usuário.
RF06 - O sistema deve permitir que o usuário crie eventos em sua agenda pessoal ou na agenda compartilhada do casal.
RF07 - O sistema deve permitir que o usuário convide o parceiro para participar de um evento.
RF08 - O parceiro deve receber as informações do convite e poder aceitá-lo ou recusá-lo.
RF09 - O sistema deve permitir visualizar eventos pessoais e compartilhados no calendário.
RF10 - O sistema deve permitir editar eventos criados pelo usuário.
RF11 - O sistema deve permitir cancelar ou excluir eventos conforme as permissões definidas.
RF12 - O sistema deve permitir cadastrar localização em um evento.
RF13 - O sistema deve permitir configurar data e horário do evento.
RF14 - O sistema deve permitir cadastrar datas especiais do relacionamento.
RF15 - O sistema deve emitir lembretes referentes a eventos e datas especiais.
RF16 - O sistema deve enviar notificações push referentes a eventos e datas especiais.


## Requisitos não funcionais:

RNF01 - O sistema deve proteger informações de autenticação e dados sensíveis do usuário.
RNF02 - As senhas dos usuários devem ser armazenadas utilizando algoritmo de hash seguro.
RNF03 - Toda comunicação entre o aplicativo e backend em produção deve utilizar HTTPS, garantindo a criptografia e proteção dos dados transmitidos.
RNF04 - o sistema deve apresentar respostas ás operações comuns de consulta sem apresentar atrasos perpeptíves ao usuário em condições normais.
RNF05 - O aplicativo deve apresentar estados de carregamento e erro durante operações assinconas ou requisições ter feedback visual para o usuário.
RNF06 - o sistema deve impedir que usuários não autorizados acessem o aplicativo e informações pertencentes a outros relacionamentos.
RNF07 - O backend deve conter um log registrando erros ou tentativas de acessos violados.
RNF08 - O aplicativo deve suportar a sistemas operacionais Android e iOS.
